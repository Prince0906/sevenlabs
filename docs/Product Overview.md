# Product Overview

**Aloud** (formerly "Seven Labs", a leftover TTS identity) is voice-first FAANG behavioral interview prep. Tagline: *"Interview prep, out loud."* You speak your answers; Aloud scores them against the company's real rubric and tells you the [[Signal Levels|level]] you read as.

## Two surfaces
1. **[[Speaking Coach]]** — the turn-based practice mode that exists today. Record an answer → Whisper transcript → delivery analysis (WPM, fillers, pauses) → a 2-sentence GPT coach reply (spoken back via TTS) → optional rubric scoring. Modes: see [[Coaching Modes]].
2. **[[Bar-Raiser Panel]]** — the real-time "confidence engine": three AI interviewers in a live voice loop, then a committee verdict. This is the [[Moat|moat]].

## What makes it different
- It grades **strategic content**, not just delivery — the senior-vs-junior signal nobody else reads (see [[Competitive Landscape]]).
- The output is an honest [[Judgment Pipeline|report]], not applause.
- The metric that matters is [[Confidence Metric|composure under pressure]], built through repeated rehearsal ([[Evidence Base]]).

## Brand
Name **Aloud**, tagline *"Interview prep, out loud,"* support `support@aloud.app` (placeholder). Domain/trademark still pending (`aloud.com` and Google's "Aloud" dubbing tool exist; preferred handles `aloud.ai` / `tryaloud.com`). Visual identity in [[Design System]].

## Status
Built on `main`, **not yet live**. The single biggest blocker is going live ([[Roadmap]] Phase 0).
