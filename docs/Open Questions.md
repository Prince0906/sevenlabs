# Open Questions

The honest list of things still unproven. Several are explicit kill-criteria.

1. **BYOK adoption at the key-wall.** An anxious new-grad is the user *least* likely to own a billing-enabled API key. What % actually bring one? (Why v1 launches on Aloud's capped key — see [[Pricing and BYOK]].)
2. **"Why leave free ChatGPT voice?"** Needs a demo that *proves* the [[Bar-Raiser Panel]] feels different. If a tester shrugs, the [[Moat]] thesis is wrong.
3. **[[Confidence Metric]] validity.** Validate the composure score against hand-labeled "felt confident" *before* it's ever a headline number. (Stated kill criterion.)
4. **Cold-start calibration.** The moat needs data it doesn't have yet — the first 100 sessions are calibrated against *what*?
5. **STT bias against non-native English speakers** — corrupts both rubric and [[Confidence Metric]] for the international FAANG-prep segment.
6. **Second company** — Google vs Meta first?
7. **How aggressively to message "senior vs junior signal"** without scaring users.
8. **Nothing is live yet** — every learning above is gated on [[Roadmap|Phase 0]].
