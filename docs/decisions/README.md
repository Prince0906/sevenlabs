# Architecture Decision Records

Short, immutable records of the load-bearing decisions. Each captures the
context at the time, the call, and its consequences. **Don't edit an accepted
ADR to change a decision — write a new one that supersedes it** and link both
ways. Current-state design lives in [`../architecture.md`](../architecture.md);
these explain *why* it is that way.

ADR-0001…0010 record the adjudicated binding decisions of the 2026-06-11
interview-engine plan; 0011–0013 distill engineering decisions from the
2026-06-12 audit; 0014–0015 record the 2026-07-14 conventions pass.
